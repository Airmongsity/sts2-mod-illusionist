# Illusionist v0.5.5

本日志描述相对已发布 `v0.5.4` 的最终净变化。发布检查器报告：新增 0 项、移除 0 项、2 张牌发生净变化；幻化复制品的共用规则变更由人工复核补充。

## 平衡性

- 【先见】的耗能由 0 调整为 1，限制玩家通过囤积大量生成的【先见】牌发育。
- 【预警】的耗能由 3 调整为 2，以补偿【先见】本身耗能的提高。

## 规则调整

- 使用【千面】、【召唤】、【返场】等效果创建幻化复制品时，结果牌不再继承模板牌的 Affliction。
- 所有正向幻化会在替换前统一清除结果牌的 Affliction，避免冻结或魂缚被批量复制；原牌自身的 Affliction 及其幻化回退关系不受影响。

## Balance

- Prescience now costs 1 Energy instead of 0, limiting the scaling available from stockpiling generated Prescience cards.
- Forewarn now costs 2 Energy instead of 3 to compensate for the increased cost of Prescience itself.

## Rules

- Transmuted copies created by Myriad Faces, Summon, Encore, and similar effects no longer inherit the template card's Affliction.
- Every forward Transmute now clears the result card's Affliction before replacement. This prevents Frozen or Soulbound from being multiplied while preserving the original card's Affliction and Transmute-revert relationship.
