# Illusionist v0.5.6

本日志描述相对已发布 `v0.5.5` 的最终净变化。发布检查器报告：注册内容新增 0 项、移除 0 项、变化 0 项；兼容性、跨角色镜像显示与开发工具变更由人工复核补充。

## 兼容性

- 适配 Slay the Spire 2 v0.111.0 的角色动画器接口。
- 非幻术师角色获得镜像后，现在可以看到并打开镜像牌堆；镜像牌堆按钮使用当前角色头像。
- 镜像复制体现在使用其拥有者的角色外观。原版角色与提供自定义外观路径的 MOD 角色均受支持；幻术师继续使用自身的半透明 Spine 外观。

## 开发工具

- 新增可重复运行的原版游戏内容提取管线，可从当前安装版本提取 cards、relics、potions、monsters、powers、rooms 与 ancients。
- 提取结果包含英文标题与描述、卡牌升级差异、怪物行动状态机和确定性 JSON/Markdown 输出，并可比较不同游戏版本。
- 将 `game-facts.md` 调整为适用于所有 Slay the Spire 2 MOD 的通用机制文档。

## Compatibility

- Updated the character animator integration for Slay the Spire 2 v0.111.0.
- Characters other than the Illusionist can now see and open the Mirror pile after gaining Mirror Image; the pile button uses the current character's icon.
- Mirror clones now use their owner's character visuals. Base-game characters and MOD characters that provide a custom visuals path are supported; the Illusionist retains her translucent Spine appearance.

## Developer Tooling

- Added a reusable base-game content extraction pipeline for cards, relics, potions, monsters, powers, rooms, and ancients from the currently installed game version.
- Extracted data includes English titles and descriptions, card upgrade differences, monster move state machines, deterministic JSON/Markdown output, and cross-version diffs.
- Generalized `game-facts.md` into a mechanics reference suitable for all Slay the Spire 2 MOD projects.
